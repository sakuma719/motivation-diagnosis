# Motivation Diagnosis

制御焦点理論をもとにした社内研修用の診断WEBアプリ

## 起動

依存パッケージやビルドは不要です。`index.html` をブラウザで開くか、このディレクトリで以下を実行してください。

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

## 診断の仕組み

- 全6問を1問ずつ表示し、1〜5の5段階で回答します。回答後は自動で次へ進みます。
- 「前の質問へ」で回答を変更できます。変更せず進む場合は「次の質問へ」を使用します。
- 促進焦点はQ1＋Q3＋Q5、予防焦点はQ2＋Q4＋Q6。各3〜15点、逆転採点なし。
- 10〜15点は高め、9点は中間、3〜8点は控えめです。
- 高め／控えめはタイプA、高め／高めはB、控えめ／控えめはC、控えめ／高めはDです。
- 片方でも9点なら「中間タイプ」です。点差での分類は行いません。
- 全問回答で促進焦点・予防焦点の説明ページを表示し、「診断結果を見る」で結果・得点・横棒グラフを表示します。説明ページから最後の質問へ戻って回答を見直せます。やり直すと回答は初期化されます。
- 回答はブラウザ内で処理し、外部への送信・永続保存は行いません。

このチェックは、制御焦点理論をもとにした簡易版です。正式な心理検査や人事評価には使えません。

## 動作確認

6問の順序と文面、回答変更と回答保持、未回答時の結果非表示、採点の3・8・9・10・15点の境界、全4タイプと中間タイプ、グラフ、リセット、キーボード操作、PC・スマートフォン表示を確認します。

## WEBプレビューへの対応

`index.html` にはCSSとJavaScriptを埋め込んでおり、単独で開いても動作します。外部ファイルの配信パスに依存しません。開始画面の「診断を始める」から質問へ進み、全問回答後に説明ページを表示し、そこから結果へ進みます。やり直すと回答を消去して開始画面へ戻ります。

CSS・JavaScriptの編集元は `style.css` と `app.js` です。変更後は `python3 scripts/sync-inline.py` を実行してHTMLに反映してください。同期処理は依存パッケージ不要です。プレビュー機能自体がJavaScriptの実行を禁止する場合は、スクリプトを許可するブラウザで開く必要があります。

## GitHub Pagesでの公開

GitHubのリポジトリで **Settings → Pages** を開き、**Build and deployment** の **Source** を **Deploy from a branch** に設定します。ブランチは **main**、フォルダは **/ (root)** を選び、**Save** を押してください。ビルド不要で、ルートの `index.html` が公開されます。

公開が完了したらPages画面に表示されるURLで、診断開始・回答変更・結果・4タイプ一覧・やり直しを確認してください。
